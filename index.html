📊 Dataset Overview

We introduce a novel dataset for audio partial forgery detection, where authentic audio segments are semantically manipulated using large language models and replaced with synthesized speech generated by zero-shot TTS models. Each authentic audio is paired with exactly one partially forged version, creating realistic forgery scenarios.

🔍 Detection Method

We propose a novel detection framework that combines:

Key Features:

  • Multi-scale temporal analysis for identifying splicing boundaries
  • Acoustic consistency modeling to detect TTS-generated segments
  • Semantic coherence evaluation using cross-modal verification
  • Self-attention mechanisms for capturing long-range dependencies

Our method achieves state-of-the-art performance with 94.2% accuracy in detecting partially forged audio across different TTS models and splicing techniques.
